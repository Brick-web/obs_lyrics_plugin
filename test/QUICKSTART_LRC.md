# LRC 歌词文件支持 - 快速开始指南

## 升级概述

你的 OBS 歌词插件现已支持 **LRC 歌词格式**！除了原有的 JSON 格式外，现在可以直接使用 `.lrc` 歌词文件。

## ✨ 新增功能特性

### 1. 自动检测和转换
- ✅ 自动识别 `.lrc` 和 `.json` 文件
- ✅ LRC 文件自动转换为内部格式，无需手动操作
- ✅ 支持混合使用 LRC 和 JSON 文件

### 2. LRC 格式支持
- ✅ 标准 LRC 格式：`[mm:ss.xxx] 歌词`
- ✅ 自动提取元数据：`[ti:标题]`, `[ar:艺术家]`
- ✅ 自动计算每句的显示时长
- ✅ 支持多种行尾格式（Windows/Unix/Mac）

### 3. 扫描系统升级
- ✅ `scanAndGenerateConfig()` 现在识别 LRC 文件
- ✅ 自动生成包含 LRC 和 JSON 文件的 playlist

## 🚀 使用方法

### 最简单的方式：自动扫描

1. 将 `.lrc` 文件放入 `lyrics/` 目录
2. 打开控制端 → ⚙️ 设置 → 🛠️ 系统维护
3. 点击 "🔄 扫描并更新配置"
4. 完成！刷新页面即可使用

### 手动添加

1. 编辑 `config/playlist.json`
2. 添加条目：
```json
{
  "id": "song_X",
  "title": "歌曲名",
  "path": "lyrics/filename.lrc"
}
```

## ⚙️ 技术细节

### 时长计算原理
```
每句时长 = 下一句时间戳 - 当前句时间戳
```

### 支持的 LRC 格式
```
[ti:歌曲标题]
[ar:歌手名]
[00:00.000] 第一句歌词
[00:03.500] 第二句歌词
[00:07.000] 第三句歌词
```

### 自动优化
- 最小时长：500ms（防止闪烁）
- 最后一句：默认 3000ms
- 行尾兼容：自动处理 \n, \r\n, \r

## 🔍 常见问题

**Q: 加载了 LRC 文件但歌词没有显示？**
- A: 检查 LRC 文件格式是否正确，参考上面的标准格式

**Q: 时长显示不对？**
- A: 可以在编辑器中修改对应的 JSON 版本，或编辑 LRC 时间戳

**Q: 如何同时使用 LRC 和 JSON？**
- A: 可以，`playlist.json` 中同时指向两种格式的文件

**Q: 怎么从在线资源导入 LRC？**
- A: 下载 LRC 文件放入 `lyrics/` 目录，使用扫描功能即可
