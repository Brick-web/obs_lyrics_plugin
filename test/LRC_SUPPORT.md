# LRC 文件支持升级

## 概述

项目已升级以支持 **LRC 歌词格式**（`.lrc` 文件），除了原有的 JSON 格式外。LRC 是一种常见的歌词格式，每行包含时间戳和对应的歌词。

## 新增功能

### 1. LRC 解析器 (`js/lrcParser.js`)

新增模块提供以下功能：
- **`parseLrc(content)`** - 解析 LRC 格式内容，返回 JSON 对象
- **`parseLrcFile(fileOrContent)`** - 异步解析 File 对象或字符串
- **`isLrcFile(filename)`** - 判断文件是否为 LRC 格式

#### 用法示例
```javascript
import { parseLrc, parseLrcFile } from './js/lrcParser.js';

// 方法 1: 直接解析字符串
const result = parseLrc(`[ti:歌曲名]
[00:00.000] 第一句歌词
[00:03.500] 第二句歌词`);

console.log(result.title);     // "歌曲名"
console.log(result.lyrics);    // [{text: "...", duration: ...}, ...]
```

### 2. 控制端改进 (`control.html`)

#### 自动文件类型检测
- `loadSong()` 函数现在能自动识别文件类型
- 若为 `.lrc` 文件，自动使用 LRC 解析器转换为内部格式
- 若为 `.json` 文件，保持原有逻辑

#### 扫描系统升级
- `scanAndGenerateConfig()` 现在能扫描 `.lrc` 文件
- 自动提取 LRC 的 `[ti:标题]` 作为歌曲名
- 同时支持 JSON 和 LRC 混合的歌词库

### 3. 支持的 LRC 格式

```
[ti:歌曲标题]
[ar:歌手名]
[al:专辑名]
[00:00.000] 歌词行1
[00:03.500] 歌词行2
[00:07.000] 歌词行3
```

**特性：**
- ✅ 支持毫秒精度时间戳 `[mm:ss.xxx]`
- ✅ 支持秒级精度 `[mm:ss]`（自动补 0）
- ✅ 自动跳过空歌词行
- ✅ 自动计算每句歌词的时长
- ✅ 支持元数据行 `[ti:]`, `[ar:]`, `[al:]`, `[au:]` 等

## 使用指南

### 方式 1: 手动添加歌曲

1. 将 `.lrc` 文件放入 `lyrics/` 目录
2. 编辑 `config/playlist.json`，添加条目：
```json
{
  "id": "song_X",
  "title": "歌曲名",
  "path": "lyrics/filename.lrc"
}
```
3. 刷新控制端页面

### 方式 2: 自动扫描（推荐）

1. 将 `.lrc` 文件放入 `lyrics/` 目录
2. 打开控制端 → ⚙️ 设置 → 🛠️ 系统维护
3. 点击 "🔄 扫描并更新配置"
4. 选择项目根目录 `obs-lyrics-plugin`
5. 等待扫描完成，自动生成配置

## 时长计算说明

系统自动计算每句歌词的显示时长：

```
每句时长 = 下一句的时间戳 - 当前句的时间戳
```

例如：
```
[00:00.000] 第一句        → 时长 = 03000 - 00000 = 3000ms
[00:03.000] 第二句        → 时长 = 06000 - 03000 = 3000ms
[00:06.000] 最后一句      → 时长 = 3000ms（默认）
```

## 文件格式对比

### LRC 格式优点
- 纯文本，易于编辑和版本控制
- 文件体积小
- 网络上有大量已有资源
- 支持多个标准和工具

### JSON 格式优点
- 直接使用，无需转换
- 结构清晰，便于编程操作
- 可以保存额外的元数据（艺术家、专辑等）

### 混用建议
- 优先使用 `.lrc` 格式存储大量歌词
- 对特殊需求的歌曲，保存 `.json` 版本
- 两种格式可以在同一项目中共存

## 技术细节

### 时间戳格式
- 支持：`[mm:ss.xxx]` - 毫秒精度
- 支持：`[mm:ss]` - 秒级精度
- 不支持：`[hh:mm:ss]` - 超过 59 分钟需改为 `mm:ss` 格式

### 元数据支持
解析器会自动提取：
- `[ti:...]` - 标题
- `[ar:...]` - 艺术家
- `[al:...]` - 专辑（存储但未在 UI 中展示）
- `[au:...]` - 作者（存储但未在 UI 中展示）

### 时长最小值
- 最小时长被限制为 500ms（防止闪烁）
- 最后一句默认 3000ms（可自定义编辑）

## 常见问题

### Q: 如何编辑 LRC 歌词的时长？
A: 暂时需要：
1. 在编辑器中修改对应的 JSON 版本
2. 或使用外部 LRC 编辑器修改时间戳

### Q: LRC 文件如何更新到显示端？
A: 自动生效。加载歌曲时实时解析 LRC 文件，无需重启显示端。

### Q: 可以混合 JSON 和 LRC 吗？
A: 可以。`playlist.json` 中可以同时指向 `.json` 和 `.lrc` 文件。
